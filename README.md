# Small Space, Smart Life — GitHub Pages Website

This folder contains the multi-page static website structure for Small Space, Smart Life.

## Publish on GitHub Pages
1. Create a GitHub account.
2. Create a new repository named `smallspacesmartlife`.
3. Upload all files and folders from this package.
4. In the repository, open Settings → Pages.
5. Choose Deploy from a branch.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide the live Pages URL.

## Important
- Replace `#` social links with the real profile URLs.
- Replace placeholder article/product cards with original content.
- The `Advertisement` boxes are layout placeholders for future AdSense integration.
- Do not add real AdSense code until the site/content is ready and the AdSense account is approved.
- Product recommendations should use real product information and clearly disclosed affiliate links.
